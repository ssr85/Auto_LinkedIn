🚀 Quick Start Path:

Step 1: Setup (15 min)
   → Run: ./setup.sh
   → Edit: .env (add API keys)
   → Run: python get_linkedin_token.py

Step 2: Validate (2 min)
   → Run: python main.py validate

Step 3: Test (10 min)
   → Run: python main.py research
   → Check Trello, approve a topic
   → Run: python main.py process
   → Check Trello, approve content
   → Run: python main.py publish
   → Check LinkedIn!

Step 4: Automate (1 min)
   → Run: python main.py schedule

💡 What Each Component Does:

🔍 Research Agent:
   - Analyzes your target URL
   - Searches for industry trends
   - Creates detailed topic outlines
   - Sends to Trello for approval

✍️  Content Agent:
   - Takes approved topics
   - Generates LinkedIn-optimized posts
   - Reviews and polishes content
   - Sends to Trello for approval

📋 Trello Integration:
   - Creates cards for topics
   - Creates cards for content
   - Monitors for approvals
   - Archives after publishing

💼 LinkedIn Integration:
   - Posts approved content
   - Validates authentication
   - Handles API rate limits

⏰ Scheduler:
   - Runs research daily
   - Checks approvals hourly
   - Manages all automation
