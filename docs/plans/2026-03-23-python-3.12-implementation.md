### Task 1: Install Python 3.12.12

**Files:**

### Task 2: Configure Global Version

**Step 1: Set global version**

Run: `pyenv global 3.12.12`
Expected: `pyenv` updates the global shim.

**Step 2: Rehash pyenv**

Run: `pyenv rehash`
Expected: Shims are updated.
